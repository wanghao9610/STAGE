# 项目记忆

**语言：** [English](memory_spec.md) | 简体中文

一次会话把学到的东西记在哪里，又怎么传到下一次。决定**要不要记**的规则——先提议再写、绝不擅自决定，仓库自己的文件优先——在 `AGENTS.md` §10，这里不重复。这份文件是那条规则两头都要踩的格式：记忆库里放什么、单条记忆长什么样、会话钩子解析的是什么。

## 什么该记在这里

只有一条判据，而且是排他的：**只有当仓库里没有任何文件已经认领这条事实时，它才属于记忆。** 数字属于 `mates/` 里带指纹的那一条，论断属于 `notes/claims.md`，页数上限和截稿日期属于该周期的 `venue.yml`，被引论文说了什么属于 `notes/refs/`，向审稿人做出的承诺属于 `tasks/<cycle>_promises.md`，会场事务属于 `tasks/<cycle>_venue.md`。记忆是残余——跨运行仍然成立、又没有任何文件认领的那部分。没有这条判据，记忆库就成了论断台账和笔记已经回答过的问题的第二个答案，两边随后各走各的。

这条排他性最要紧的一刀落在虚构边界上（规约 §9）：**记忆永远不是某个数字、某条会场规则、某句关于被引论文的断言的来源。** 那些东西各有其家，正是因为它们必须可核查；而一个回忆出来的值，无论由哪个文件回忆，都仍是没有来源的。

| 类型 | 装什么 | 例子 |
|---|---|---|
| `env` | 关于某台机器或某套 TeX 工具链的事实，通常是踩坑换来的 | 这台机器的 TeX Live 没有 `newtxtext`，`arxiv.cls` 只有在 `LATEX_ENGINE=xelatex` 下才编得过 |
| `pref` | 用户对"写作该怎么推进"的长期偏好 | 一次只交一节草稿并停下来等评审，绝不成批交 |
| `insight` | 活得比产生它的那次运行更久的判断 | 上游 `results.md` 每次重跑都会重排行号，所以 `% src:` 锚点要指表格 id，绝不能指行号 |
| `deadend` | 试过、被否掉、不值得再试的事，连同它的代价 | 把贡献框成一个新 benchmark；模拟评审组读成增量工作，改了一整版引言后又退回方法框架 |

`deadend` 是论文仓库最需要、而通用记忆装不下的一类：跨周期而言，贵的知识是哪种框架、哪次删减、哪个排版已经试过且没活下来。

## 存在哪里

```text
.stage/memory/
├── MEMORY.md          # 索引：每条记忆一行
├── <slug>.md          # 一事一文件
└── local/             # 只对本机成立的记忆，git 忽略
    ├── MEMORY.md
    └── <slug>.md
```

`.stage/memory/` 入库，所以一条记忆活得比记下它的那台机器更久，也跟着 clone 一起走。`local/` 像 `.env` 一样被忽略：在这里成立、换台机器就不成立的路径、字体、缺失的 LaTeX 宏包或引擎怪癖归它。这类事实若仍值得带走，另一条路是写成共享记忆，并在 `scope` 里点明它成立的那台机器。

## 单条记忆文件

一事一文件，文件名就是它的 slug：

```markdown
---
type: env
scope: machine:mbp-a
language: zh
verified: 2026-08-03
source: wkdrs/builds/main.log
---

这台机器上 `arxiv.cls` 只有在 `LATEX_ENGINE=xelatex` 下才编得过。

**为什么：** 这里的 TeX Live 没装 `newtxtext`，pdflatex 在导言区就停了。
**怎么用：** 把引擎写进 `.env`，别写在命令行上——每个 skill 都通过 `execs/run.sh` 编译。
```

| 字段 | 是什么 |
|---|---|
| `type` | 上面四类之一；只有 `env` 会被钩子按时间标记 |
| `scope` | `global`、`machine:<name>`、`cycle:<cycle>` 或 `manus:<path>`——事实在哪里成立，不是在哪里学到的 |
| `language` | 正文语言（规约 §7.6，回复语言规则）；frontmatter 的键始终英文 |
| `verified` | 最后一次确认它为真的日期，取自系统时钟（规约 §4，真实日期） |
| `source` | 这条事实是从哪个产物里出来的，或者 `conversation` |
| `supersedes` | 可选：这条记忆取代了哪个 slug |

正文第一句把事实说完，之后只写读者据此行动所需的那些。记忆自己不留历史：复核就地改写 `verified`，而不是往后追加；它从前说过什么，在 git 里。

**语言规则只管正文。** `STAGE_LANG` 管的是一次运行**写下**什么（规约 §7.6），所以中文会话记的是中文正文——而 frontmatter 的每个键、上表里的每个取值、索引行里的 `<类型>` token 都保持英文，因为钩子和这份规范都按字节匹配它们。

## 索引行

`MEMORY.md` 和这些文件并排放着，每条记忆一行，新的在上：

    - <类型> · <适用范围> · <最后确认日期> · [<slug>](<slug>.md) — <一句话>
    - env · machine:mbp-a · 2026-08-03 · [xelatex-only](xelatex-only.md) — arxiv.cls 在这台机器上只有 xelatex 编得过

前四个字段之间是"空格 + 中点 + 空格"；破折号之后是自由文本，写什么都行，包括那个分隔符本身。**会话钩子就是按它逐字节切分的**——把分隔符改个写法，它们会不声不响地什么都不再标记，哪里都不会报错。时效标记对类型字段同样只认字面：`env` 保持英文，一句话用什么语言写都不影响。只有以 `- ` 开头的行会被读，所以索引文件自己的说明头对它们不可见。

一次会话判断相关性靠的就是这一句，所以它要说这条事实**是什么**，而不是它关于什么："arxiv.cls 在这台机器上只有 xelatex 编得过"，而不是"关于编译引擎的笔记"。索引控制在 60 行上下；超过就把条目按类型分组、各组加一个小标题——仍在这个文件里，绝不另开一个：钩子不把任何别的文件当索引读，拆出去的那份会不声不响地再也到不了会话，而小标题不过是又一种它们跳过的行。

## 一条记忆怎么退场

三条路，第一条最常走：

- **复核通过**——事实仍然成立：把 `verified` 改成今天，再把新日期带进这条记忆的索引行——陈旧标记读的是那一行，不是 frontmatter。
- **被取代**——事实变了：写新的那条并带上 `supersedes: <旧 slug>`，然后删掉旧文件和它的索引行。历史在 git 里，记忆库内部不做归档——正是这一点让索引短到每次会话都注入得起。
- **本来就错**——直接删。从来不成立的记忆不是值得留的历史。

删掉一条记忆和别的删除一样：每个介入档位下都要向用户确认（规约 §7.7，各 skill 问多少）。

一个周期结束不构成退场理由。来自某次已冻结投稿的 `cycle:<cycle>` 记忆，对那个周期仍然为真，也保留它的 scope；让它退场的是"错了"，不是"旧了"。

## 它怎么到达一次会话

| 运行时 | 钩子 | 事件 | 注入什么 |
|---|---|---|---|
| Claude Code | `.claude/hooks/stage_memory.sh` | `SessionStart` | 索引，装在 `additionalContext` 里 |
| Codex | `.codex/hooks/stage_memory.sh` | `SessionStart` | 索引，装在 `additionalContext` 里 |
| Cursor | `.cursor/hooks/stage_memory.sh` | `sessionStart` | 索引，装在 `additional_context` 里 |
| Kimi | `.kimi-code/hooks/stage_memory.sh` | `UserPromptSubmit` | 索引，每次会话注入一次 |

每个钩子只打印那两份索引，别的什么都不打——共享的那份，以及 `local/` 那份（存在的话）。`verified` 距今超过 180 天的 `env` 行，会在会话看到的内容里被标为陈旧，因为机器会在一条关于它的事实底下悄悄改变；另外三类不按时间标记——死路一直是死路，而一个在健康条目上也会亮的标记，只会教读者跳过它。记忆库没有条目时它什么都不打印，所以什么都没记过的论文一分钱不花。

钩子存在不等于已注册。Claude、Codex、Cursor 出厂就在 `.claude/settings.json`、`.codex/hooks.json`、`.cursor/hooks.json` 里注册好了；Kimi 没有项目级配置，靠 `bash .kimi-code/hooks/install.sh` 每台机器注册一次。在 Codex 上，注册好也还没开始跑：要先信任该项目，再在 CLI 里用 `/hooks` 批准这个钩子。在这个钩子出现之前就接入的论文仓库，保留的是它自己的注册文件，`execs/update.sh` 从不覆盖它——它只会把这个缺口报出来，那一条由人手工补上。
